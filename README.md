# Mój Słownik 🇵🇱

Личное iOS-приложение для изучения польского языка с русского: добавляете слово —
перевод подставляется автоматически, учите через флешкарточки с интервальным
повторением и викторину, сканируете слова камерой прямо из книг и вывесок.

Всё хранится локально на iPhone. Никакой авторизации, синхронизации и серверов.

## Возможности

- ➕ **Быстрое добавление**: вводите слово на русском или польском — язык
  определяется сам, перевод появляется автоматически (его можно поправить).
- 📷 **Сканер**: наведите камеру на текст, коснитесь слова — оно готово
  к добавлению.
- 🃏 **Флешкарточки** с интервальным повторением (алгоритм как в Anki):
  сложные слова показываются чаще.
- ✅ **Викторина**: выберите правильный перевод из четырёх.
- 🔊 **Озвучка** польского произношения (офлайн, системный синтез речи).

## Установка на iPhone (без App Store)

Понадобятся: Mac с Xcode (бесплатно из Mac App Store), iPhone, кабель
и обычный Apple ID (платный аккаунт разработчика не нужен).

### Первый раз

1. **Xcode → Аккаунт.** Откройте Xcode → меню Xcode → Settings → Accounts →
   «+» → войдите со своим Apple ID.
2. **Сгенерируйте проект** (если файла `MojSlownik.xcodeproj` ещё нет):
   ```sh
   brew install xcodegen   # один раз
   cd my-dictionary
   xcodegen generate
   ```
3. **Откройте `MojSlownik.xcodeproj`** в Xcode. В настройках таргета
   `MojSlownik` → вкладка **Signing & Capabilities** → в поле **Team**
   выберите свой Apple ID (Personal Team).
4. **Подключите iPhone кабелем.** На iPhone нажмите «Доверять этому
   компьютеру».
5. **Включите режим разработчика** на iPhone: Настройки → Конфиденциальность
   и безопасность → **Режим разработчика** → включить → перезагрузка.
   (Пункт появляется после первого подключения к Xcode.)
6. В Xcode вверху выберите свой iPhone как устройство запуска и нажмите
   **Run (⌘R)**.
7. Первый запуск iOS заблокирует: на iPhone откройте Настройки → Основные →
   **VPN и управление устройством** → нажмите на свой Apple ID → «Доверять».
   Запустите приложение ещё раз.

### Каждые 7 дней

Бесплатная подпись живёт 7 дней — потом приложение перестаёт открываться
(данные при этом **не** пропадают). Чтобы продлить:

1. Подключите iPhone к Mac.
2. Откройте проект в Xcode и нажмите Run (⌘R).

Всё, ещё 7 дней работы. Слова хранятся в базе приложения и переустановку
переживают.

## Перевод: как это работает

- На iOS 17 перевод берётся из бесплатного веб-API Google Translate
  (а при его недоступности — [MyMemory](https://mymemory.translated.net)) —
  при добавлении слова нужен интернет.
- Если обновите iPhone до **iOS 18+**, приложение автоматически перейдёт на
  системный офлайн-перевод Apple (при первом использовании iOS предложит
  скачать языковые пакеты русского и польского).
- Перевод всегда можно отредактировать перед сохранением.
